🎯 ЗАДАЧА
─────────────────────────────────────────────────────────────────────────────
Написать Python-скрипт для реверс-инжиниринга параметров цилиндрических 
прямозубых зубчатых передач (одной шестерни или пары) с использованием:
  • Гибридного подхода (формирование пула модулей + численная оптимизация)
  • Многопроцессорности для ускорения расчётов
  • Plotly для интерактивной визуализации

ФУНКЦИОНАЛЬНОСТЬ
─────────────────────────────────────────────────────────────────────────────

✅ ДВА РЕЖИМА ВВОДА:
   • CLI:           python gear_calc.py 52 46 20
                    python gear_calc.py 50 45 20 100 95 40 75
   • Интерактивный: python gear_calc.py

✅ АНАЛИЗ ОДНОЙ ИЛИ ДВУХ ШЕСТЕРЁН:
   • Одна шестерня:  независимая оптимизация x₁, ha*, c*
   • Пара:           общие ha*, c* + независимые x₁, x₂ + ограничение aw

✅ ГИБРИДНЫЙ ПОДХОД:
   • Сетка модулей:          равномерная от 0.5 до 10.0 мм (шаг 0.1)
   • ГОСТ стандарты:         ~17 модулей из ГОСТ 9563-60
   • Дюймовые питчи (DP):    11 питчей, переведённых в метрику
   • Объединённый пул:       ~110 уникальных модулей

✅ МНОГОПРОЦЕССОРНОСТЬ:
   • ProcessPoolExecutor с max_workers=os.cpu_count()
   • Независимая оптимизация для каждого модуля
   • Линейное масштабирование по числу ядер процессора
   • Время выполнения: 90-120 сек на 8-ядерной системе

✅ МАТЕМАТИЧЕСКАЯ ОПТИМИЗАЦИЯ:
   • Метод: scipy.optimize.least_squares
   • Целевая функция: сумма квадратов невязок расчётных vs заданных параметров
   • Несколько стартовых точек: сетка 3×3 по x и ha* для избежания локальных минимумов
   • Bounds (ограничения): x ∈ [-1.5, 1.5], ha* ∈ [0.5, 1.2], c* ∈ [0.15, 0.4]

✅ ВЫВОД РЕЗУЛЬТАТОВ:
   • Фильтрация по допуску (TOLERANCE = 5.0 мм, настраивается)
   • Сортировка по возрастанию ошибки
   • Таблица через rich с топ-20 результатами
   • Маркировка: ГОСТ * — совпадение со стандартом, DP XX — дюймовый питч

✅ ИНТЕРАКТИВНАЯ ВИЗУАЛИЗАЦИЯ:
   • График 1: Модуль vs Ошибка (Scatter+Line с маркерами ГОСТ/DP)
   • График 2: Смещение vs Модуль (Scatter с Viridis colorscale по ошибке)
   • HTML файл: gear_results.html (4.7 МБ, полностью автономный)
   • Интерактивность: hover, zoom, pan, сохранение в PNG
