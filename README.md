# GearSolver — Реверс-инжиниринг параметров зубчатых передач

Производственно-готовый Python-скрипт для определения параметров цилиндрических прямозубых зубчатых передач (одной шестерни или пары) с использованием гибридного подхода, многопроцессорности и интерактивной визуализации.

## 🎯 Возможности

- ✅ **Два режима ввода:** CLI аргументы или пошаговый интерактивный ввод
- ✅ **Анализ одной шестерни или пары:** Независимая работа с одним или двумя элементами
- ✅ **Гибридный подход:** Сочетание сетки модулей + математическая оптимизация
- ✅ **Широкий пул модулей:** Сетка от 0.5 до 10 мм + стандарты ГОСТ + дюймовые питчи (DP)
- ✅ **Параллелизм:** Использование `ProcessPoolExecutor` для распределения вычислений на все ядра
- ✅ **Минимизация невязки:** Использование `scipy.optimize.least_squares` с несколькими стартовыми точками
- ✅ **Маркировка стандартов:** Автоматическое обозначение совпадений с ГОСТ (⭐) и DP (e.g., DP 10)
- ✅ **Красивый вывод:** Таблица результатов через `rich`
- ✅ **Интерактивные графики:** Два subplot'а Plotly с 3D-визуализацией пространства решений

## 🚀 Использование

### 1. CLI режим (одна шестерня)

```bash
python gear_calc.py 52 46 20
```

Параметры: `da1 df1 z1 [aw]`
- `da1` — диаметр вершин шестерни 1 (мм)
- `df1` — диаметр впадин шестерни 1 (мм)
- `z1` — число зубьев шестерни 1
- `aw` — межосевое расстояние (мм, опционально, по умолчанию 0)

### 2. CLI режим (пара шестерён)

```bash
python gear_calc.py 50 45 20 100 95 40 75
```

Параметры: `da1 df1 z1 da2 df2 z2 [aw]`
- `da1, df1, z1` — параметры шестерни 1
- `da2, df2, z2` — параметры шестерни 2
- `aw` — межосевое расстояние (опционально)

### 3. Интерактивный режим

```bash
python gear_calc.py
```

Скрипт пошагово запросит:
1. Количество шестерён (1 или 2)
2. Параметры каждой (введите 0 для неизвестных значений)
3. Межосевое расстояние (опционально)

## 📐 Математическая модель

### Формулы

Для каждого модуля `m` и числа зубьев `z`:

```
da = m * (z + 2*ha_star + 2*x)
df = m * (z - 2*(ha_star + c_star) + 2*x)
```

Для пары шестерён (общие `ha_star`, `c_star`):

```
aw = m * (z1 + z2) / 2 + m * (x1 + x2)
```

### Оптимизация

**Целевая функция:** Сумма квадратов невязок

```
error = sqrt(Σ(residual_i²))
```

Где `residual_i` = расчётное значение − заданное значение

Минимизация выполняется `scipy.optimize.least_squares` с:
- Несколькими стартовыми точками (3×3 сетка по `x` и `ha_star`)
- Выбором результата с минимальной ошибкой
- Bounds для физически корректных решений

### Маркировка стандартов

После оптимизации модуль проверяется на совпадение:
- **ГОСТ:** `|m - gost_m| ≤ 0.005` → `*`
- **DP:** `|m - 25.4/dp| ≤ 0.005` → `(DP XX)`

## 🐛 Обработка ошибок

Скрипт корректно обрабатывает:
- ❌ Неправильное количество CLI аргументов → переход в интерактивный режим

- ❌ Отсутствие решений в пределах допуска → информационное сообщение
- ❌ EOF при интерактивном вводе → корректное завершение
